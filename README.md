# Ore Else Collective — public recruitment website (v2)

Open `index.html` to preview. Keep `index.html`, `styles.css`, `script.js`, and `ore-else-logo.png` together when publishing. This is a static, mobile-responsive recruitment page and requires no build system.

## Publishing

Upload these files to any static host (GitHub Pages, Netlify, Cloudflare Pages). Set `index.html` as the home page. Configure a domain if desired. No site hosting or domain has been purchased or connected.

## Recruitment

Recruiters: Megyn Kelly and ZippinAlong. Every applicant must contact a recruiter, join Discord, complete EVE-HR ESI verification, and submit an in-game application; order is flexible, all steps mandatory.

Verify both links before publishing, and confirm public recruitment claims/terms with leadership.
